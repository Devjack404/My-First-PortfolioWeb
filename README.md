# 🌐 My First Portfolio Web

A personal portfolio website to showcase my skills, projects, and contact information as a developer.

---

## 🚀 Overview

This website was created as a first step in building my personal brand in the tech industry. It highlights who I am, the skills I have, and the projects I’ve worked on.

---

## ✨ Features

* 🎯 Clean and modern design
* 📱 Fully responsive (mobile-friendly)
* 🧑‍💻 About Me section
* 🛠️ Skills showcase
* 📂 Projects showcase
* 📬 Contact section
* 🎨 Simple and intuitive UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)

## ⚙️ Installation & Usage

1. Clone the repository:

```bash
git clone https://github.com/Devjack404/My-First-PortfolioWeb.git
```

2. Navigate into the project folder:

```bash
cd My-First-PortfolioWeb
```

3. Open the project in your browser:

```bash
open index.html
```
