# 🌐 My First Portfolio Web

Personal portfolio website untuk menampilkan skill, project, dan informasi kontak sebagai seorang developer.

## 🚀 Overview
Website ini dibuat sebagai langkah awal dalam membangun personal branding di dunia teknologi. Project ini menampilkan informasi tentang saya, skill yang dimiliki, serta beberapa project yang telah dibuat.

## ✨ Features
- 🎯 Tampilan modern dan sederhana
- 📱 Responsive (mobile-friendly)
- 🧑‍💻 Section About Me
- 🛠️ Skill showcase
- 📂 Project showcase
- 📬 Contact section
- 🎨 UI clean dan mudah dipahami

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
